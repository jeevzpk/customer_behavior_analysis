# customer_behavior_analysis
Built an end-to-end customer behavior analysis project using Python, PostgreSQL, and Power BI. Performed data cleaning with Python and stored structured data in PostgreSQL for efficient querying. Created interactive Power BI dashboards to visualize trends and generate actionable insights.

# End-to-End Workflow

## Overview

This project demonstrates a complete data analytics workflow, starting from data loading and exploration to visualization and insights generation. The objective is to extract meaningful insights from raw data using Python, SQL, and Power BI, and present them in a clear and interactive format.

## Dataset

* Source: Kaggle
* Format: CSV
* Description: The dataset contains structured information used for analysis, including key attributes relevant to the problem domain.

## Tools & Technologies

* **Python** (Pandas, NumPy, Matplotlib, Seaborn)
* **SQL (PostgreSQL Server)**
* **Power BI**
* **Jupyter Notebook / VS Code**

---

## Steps Performed

### 1. Data Loading

* Imported dataset using Python (Pandas)
* Verified structure and data types

### 2. Exploratory Data Analysis (EDA)

* Checked missing values and duplicates
* Performed statistical analysis
* Created visualizations (bar charts, histograms, heatmaps)

### 3. Data Cleaning

* Handled missing values
* Removed duplicates
* Standardized formats and corrected inconsistencies

### 4. SQL Analysis

* Loaded cleaned data into PostgreSQL
* Wrote queries for:

  * Aggregations
  * Filtering and grouping
  * Business-related insights

### 5. Dashboard Creation

* Imported processed data into Power BI
* Built interactive dashboards with:

  * KPIs
  * Filters and slicers
  * Visual charts for insights

## How to Run

1. Clone the repository
2. Open the Python notebook/script and install required libraries
3. Load the dataset and run EDA & cleaning steps
4. Import cleaned data into PostgreSQL and execute SQL queries
5. Open Power BI file (.pbix) to explore the dashboard
